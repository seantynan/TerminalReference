Shell Navigation

Show the current directory

PowerShell

Get-Location

Bash

pwd

PowerShell also accepts pwd as an alias.

Change directory

PowerShell

cd C:\git\Docs\TerminalReference

Bash

cd ~/git/TerminalReference

cd .. moves up one directory in both shells.

Files & Directories

List the current directory

PowerShell

Get-ChildItem

Bash

ls

PowerShell also accepts ls as an alias for Get-ChildItem.

Show a directory tree including files

PowerShell / Windows

tree .\docs /F

Bash / Linux

tree ./docs

. means the current directory. .\docs or ./docs means the docs directory beneath it. On Windows, /F tells tree to include files as well as directories.

Create a directory

PowerShell

New-Item -ItemType Directory -Path "MyFolder"

Bash

mkdir MyFolder

For everyday use, mkdir MyFolder also works in PowerShell.

Git

Check repository status

PowerShell / Bash

git status

See configured remotes

PowerShell / Bash

git remote -v

Shows the remote repository URLs used for fetching and pushing.

Stage all current changes

PowerShell / Bash

git add .

Commit staged changes

PowerShell / Bash

git commit -m "Describe the change"

Push commits

PowerShell / Bash

git push

.NET

Build

PowerShell / Bash

dotnet build

Run tests

PowerShell / Bash

dotnet test

npm / Node

Install project dependencies

PowerShell / Bash

npm install

Run the development script

PowerShell / Bash

npm run dev

Build the project

PowerShell / Bash

npm run build
